# 이슈/PR 사용 가이드

## 이슈 생성
- New issue에서 템플릿을 선택합니다.
- 제목은 자동으로 `[FEAT]`, `[BUG]` 등 접두사가 들어갑니다.
- 템플릿 항목을 간단히 채워 주세요.

## PR 생성
- 제목은 반드시 접두사를 포함합니다.
  - `[FEAT]`, `[FIX]`, `[DOC]`, `[REFACTOR]`, `[CHORE]`, `[TASK]`, `[BUG]`
- 본문은 PR 템플릿에 맞춰 작성합니다.

## 참고
- 이슈 템플릿은 `.github/ISSUE_TEMPLATE`에 있습니다.
- PR 템플릿은 `.github/PULL_REQUEST_TEMPLATE.md`에 있습니다.
